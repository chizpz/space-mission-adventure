# Референс стиля: вертикальные анимационные ролики (TikTok)

Источник: 16 скриншотов с телефона, 16.11.2026. Цвета сняты пипеткой (Python/PIL) с PNG 1320x2868,
поэтому это значения после сжатия TikTok, а не исходные из проекта автора. Шрифты определены на глаз.

Интерфейс TikTok (плашка «Потяните вниз для фиксации скорости 2x», серые автосубтитры внизу,
лайки, поиск) к стилю роликов не относится.

## 1. Что общее у всех роликов

- Формат 9:16, плоская 2D-векторная анимация, камера почти статична, сцены режутся часто.
- Почти всегда ночь. Фон тёмный и холодный (сине-фиолетовый), а единственный тёплый свет
  идёт от источника в кадре: лампа, окна, дверной проём, экран телефона.
- Субтитры огромные, только капслок, жирный гротеск, крутятся по 1-3 слова.
  Центр текста на ~65% высоты кадра (около 1300 из 2000 px экрана: 1300 / 2000 = 0,65).
- В каждой фразе 1-2 ключевых слова выделены цветом (жёлтый или красный).
- Есть «игровой» HUD сверху: таймер, счётчик, заряд батареи, номер правила.
  Он создаёт ощущение обратного отсчёта и серии.
- Ролики сериальные: «Окна часть 1», нумерованные правила, счётчик ночей.

## 2. Субтитры

| Параметр | Как сделано |
|---|---|
| Шрифт | Очень жирный геометрический гротеск. Похоже на Montserrat Black / Gilroy Heavy, но я не могу это подтвердить |
| Регистр | Только ПРОПИСНЫЕ |
| Основной цвет | Белый, тонкая тёмная обводка + мягкая тень вниз |
| Караоке | Произнесённые слова белые, ещё не произнесённые серые (полупрозрачные). Видно на «И ПОСЛЕ / ВЕЧЕРИНКИ», «ВЕСЬ ПРОШЛЫЙ / ГОД», «НЕ СМОТРИТЕ В / ЧУЖИЕ ОКНА» |
| Акцент красный | ~#F05C57 («КОРОБКУ.»), «ЛИНЗАХ». Для угрозы и запретов |
| Акцент жёлтый | ~#FFD939 («ВЛАДА.», «ПОДЪЕЗДА», «НЕ СМОТРИТЕ»). Для имён, мест, ключевых фактов |
| Объём | 1-3 слова на экран, 1-2 строки, перенос по смыслу |
| Позиция | Нижняя средняя треть, по центру. Не перекрывает лица |

Отдельный вариант для реплик персонажа (ролик про парня в оранжевом худи):
жёлтый речевой пузырь со скруглёнными краями и хвостиком влево-вниз, рядом маленькая
аватарка говорящего. Одно слово внутри выделено чёрной плашкой с жёлтым текстом
(«ЧАЙ [ОСТЫЛ.]»). Мат зацензурен решётками: «Н####Й», «П####А».

Реплика из толпы: белый наклонённый пузырь «ОЧКАРИК!» + белая плашка-бейдж с именем
над головой («ГЛЕБ»).

## 3. HUD и графические плашки

- **Таймер / дата** слева сверху: тёмная полупрозрачная таблетка, красная точка-«запись»,
  белый капслок: «СЕНТЯБРЬ · 21:05», «СУББОТА · 02:40», «ПРОШЛЫЙ ГОД». Время меняется
  по ходу истории.
- **Счётчик** справа сверху: тёмный прямоугольник с красной рамкой, мелкая серая подпись
  «НОЧЕЙ В ЛИНЗАХ», крупная красная цифра. Растёт при ошибке героя (0 → 1).
- **LED-часы** (ролик «Окна»): красный моноширинный «цифровой» шрифт, ~#DC6361,
  «НОЧЬ – 01:12», по центру сверху. Там же вотермарк моноширинным шрифтом.
- **Батарея** (ролик про такси): иконка + «18%», потом «14%». Заряд падает, растёт тревога.
- **Правило**: тёмная карточка, жёлтая скруглённая рамка, жёлтый заголовок «ПРАВИЛО № 1»
  (~#F5D255), три пиктограммы (луна, бирюзовая дуга-линза, красный крест ~#EA4249),
  под ними белый текст. Компактный вариант: плашка с жёлтым кругом-номером «4 ГОВОРИ ВСЛУХ».
- **Звонок**: тёмная таблетка с зелёной рамкой и зелёной точкой, «МАМА · 00:42», таймер идёт.

## 4. Персонажи

Встречаются два рисунка, их не стоит смешивать в одном ролике.

**А. Без обводки, мягкие тени (линзы, ночёвка у Влада, «Окна», домофон)**
- Голова-овал, лицо минимальное: точки-глаза или дуги закрытых глаз, короткий рот-штрих,
  розовые круги румянца, без носа или с намёком.
- Тело-трапеция: худи с белыми шнурками и карманом-кенгуру, руки-цилиндры с кругами-кистями,
  тонкие тёмные ноги, белые кроссовки-овалы.
- Эмоция через глаза: огромные очки с толстыми линзами (героиня в прошлом), полуприкрытые
  веки с покраснением (усталость после ночи в линзах), круглые испуганные глаза.
- Массовка с закрытыми глазами и одинаковой улыбкой, в цветных худи
  (синее, оранжевое, зелёное, красное). Главный герой стоит ближе и крупнее.
- Героиня: тёмно-каштановые волосы до плеч с чёлкой, лавандовое худи ~#9C7FD9, кожа ~#F4C8A8.

**Б. С толстой чёрной обводкой (такси, парень в окне)**
- Тот же уровень упрощения, но контур тёмный и плотный, цвета насыщеннее.
- Девушка в жёлтом дождевике ~#FFD936 с капюшоном и тёмной лямкой сумки через грудь.
- Парень: колючие тёмные волосы, пластырь на носу, оранжевое худи, наушники на шее.
- Антагонист: лысый, серо-белое лицо, красные глаза с сосудами, щетина точками,
  шрамы со швами, грязная одежда в пятнах. Контраст с «милыми» героями и даёт страх.

## 5. Фоны и освещение

| Сцена | Палитра (пипетка) | Свет |
|---|---|---|
| Ночной город / комната героини | фиолет #25103C → #170821, окна жёлтые | Город расфокусирован, жёлтые и голубые огоньки |
| Вечеринка | тот же фиолет | Конусы прожекторов, боке-круги розовые/синие/жёлтые |
| Школа | стена #4F4E43, доска #303F38 | Ровный, приглушённый, без теней |

| Снежный дом | небо #131725, стена #674C3C | Тёплые окна, снег, луна, тёмные ели силуэтом |
| Гостиная у Влада | стена ~#AA886A | Тёплая лампа, всё в охре |
| Комната с антагонистом | потолок #F9EEDA, пол #79503B, ковёр #903238 | Пятно света с потолка, псевдо-3D перспектива |
| Фасад панельки | стена #2C303A..#615654, окна #FFFFC4 / #C4D0EB | Окна светятся тёплым и холодным, одно окно ярче всех (фокус) |
| Подъезд, домофон | #24212D, дверь #161320 | Темнота + холодный свет телефона на лице + тёплая щель двери |

Приёмы:
- Задний план размыт (глубина резкости), персонаж резкий.
- Вспышка-засветка белым на весь кадр в момент события («УСНУЛА В ЛИНЗАХ»).
- Флешбэк отличается сменой палитры (холодно-зелёная школа против фиолетовой ночи).
- Окна домов: прямоугольники 2-3 оттенков жёлтого, часть погашена.

## 6. Что я не могу подтвердить

- Точные названия шрифтов.
- Скорость появления слов и длительность сцен: по скриншотам анимацию не видно.
- Что это одна студия. По рисунку тут минимум 3-4 разных автора
  (явно указан только @deathsignal.tv).
- Цвета: TikTok пережимает видео, расхождение с исходником может быть в несколько единиц на канал.

## 7. Ограничение

Это описание приёмов, а не разрешение копировать. Персонажей, вотермарки и конкретные
сюжеты авторов в своих роликах лучше не повторять. Стиль (плоская графика, HUD, караоке-субтитры)
брать можно.
